# 원주여자고등학교 1-7 예시 자료

2026-11-07에 기존 1학년 7반에 적용한 **고1 학생 30명의 가상 수업 자료**입니다. 실제 학생의 이름·제출물·별점이나 실제 교사의 평가가 아닙니다. 최근 유행 표현과 일상 비속어의 뜻풀이를 고1 말투로 작성했습니다.

- 기존 ‘야르’ 1건은 원문과 작성자를 보존했습니다.
- 가상 학생 30명이 표현 1개씩 등록했습니다. 기존 글을 포함하면 31건, 서로 다른 표현은 27종입니다.
- ‘개빡치다’, ‘킹받네’, ‘추구미’, ‘야르’는 각각 2건입니다. 뜻풀이와 순화어가 다른 독립된 글입니다.
- 순화어 후보 62건, 원래 표현 평가 424건, 순화어 평가 736건입니다. 모든 평가는 다른 가상 학생의 표이며 자기 평가는 없습니다.
- 각 글에서 평균 4점 이상인 후보 1건씩 선택해 최종 31건을 편찬했습니다. 평균이 높아도 선택되지 않은 다른 후보는 최종 사전에 나오지 않습니다.
- 가상 참여자와 편찬 담당은 `auth.users.raw_app_meta_data`의 `synthetic`, `seed_id`로 식별됩니다. 로그인 자격 증명이나 실제 학생 계정은 만들지 않았습니다. 가상 편찬 담당의 임시 관리자 세션은 같은 트랜잭션 안에서 제거했습니다.
- 학생 설명에는 `가상 학생 NN · 예시`, 최종 예문에는 `가상 예문` 표시가 있습니다.

`wonju-1-7.mjs`에 원문·후보·출처가 있습니다. 다음 명령은 **로컬 파일만 생성**합니다.

```powershell
node supabase/examples/build-wonju-seed.mjs
```

생성 위치: `test-results/wonju-1-7/` 아래 `seed.sql`, `data.json`, `summary.json`, `dictionary.md`.

`seed.sql`은 대상 학급 ID·학교·학년·반과 기존 ‘야르’를 확인한 뒤 트랜잭션으로 반영합니다. 다른 학생의 중복 등록을 허용하는 `supabase/duplicate-words-update.sql`이 먼저 적용되어 있어야 합니다. 기존 학생의 원문은 갱신하지 않고, 고정 ID를 사용하여 재시도 시 새 글·참여자가 늘어나지 않게 했습니다. 재실행하면 이 예시의 가상 별점·편찬 선택은 초기 값으로 돌아가므로 실제 수업이 진행된 뒤에는 자동 재실행하지 않습니다.

검증: 중복 등록 관련 회귀 테스트를 포함한 DB 테스트 14개 통과. 가상 데이터 전체를 로컬 PostgreSQL에서 두 번 적용하여 중복 방지·원문 보존·자기 평가 금지·페이지 나누기·최종 편찬 수를 확인했습니다.
